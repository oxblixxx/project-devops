# Using Libraries in Excalidraw (Free Version)

The free version of Excalidraw stores your drawings and libraries in your browser session.

Although Excalidraw does not include cloud provider icon libraries (such as AWS, Azure, or Kubernetes) by default, you can easily import them from the official Excalidraw Libraries repository.

1. Open Excalidraw in your browser, also
2. Visit the Excalidraw Libraries page: [Excalidraw Libraries](https://libraries.excalidraw.com/?theme=light&sort=default&utm_source=chatgpt.com).
3. Browse or search for the library you want (for example, AWS, Azure, or Kubernetes).
4. Click **Add to Excalidraw**.
5. You will be redirected back to Excalidraw. When prompted, click **Allow** to import the library.
6. After the import is complete, click the **Library** (📚) icon in the top-right corner of the Excalidraw interface to view the imported library.
7. Select any icon from the library and click anywhere on the canvas to place it. You can also drag icons directly onto the canvas if your version supports drag-and-drop.

> **Note:** Libraries imported into the free version are stored in your browser. If you clear your browser data or switch to a different browser or device, you may need to import the libraries again.
