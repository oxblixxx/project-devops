Backup is essential for infrastructure, to return to a point of recovery of data from a disaster, which could be physical damage to the storage, ransomware or unintentional delete. For backups, there is 3-2-1 strategies, 

## 3-2-1 Backup Strategy (simple rule)
- 3 copies → 1 original + 2 backups
- 2 different storage types → e.g., disk + cloud
- 1 offsite copy → e.g., cloud like Amazon Web Services or Google Cloud

Why it matters? Protects against hardware failure, human error, and disasters.

Over the years, I have used different backup platform such as Google drive, Backblaze, iDrive.
