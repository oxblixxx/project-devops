# .NET Documentation

## Overview

This repository contains my personal notes, documentation, and references for the .NET ecosystem. It serves as a centralized knowledge base covering concepts, development, deployment, troubleshooting, and best practices that I encounter while building and deploying .NET applications.


|    Feature                  | Status                          | Runs on               | Framework            |  Hosting             |
| --------------------------- | ------------------------------- | --------------------- |--------------------- |----------------------|
| **.NET Framework**          | Legacy                          | Windows only          |`net48`, `net472`     |   IIS                |
| **.NET Core**               | Discontinued (last version 3.1) | Windows, Linux, macOS | `netcoreapp3.1`      | Kestrel + IIS/Nginx  |
| **.NET** (formerly .NET 5+) | Current                         | Windows, Linux, macOS |  `net8.0`, `net10.0` | Kestrel + IIS/Nginx  |
