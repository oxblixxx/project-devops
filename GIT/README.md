| Type         | When to use it                                    |
| ------------ | ------------------------------------------------- |
| **feat**     | You added something *new* users can use           |
| **fix**      | You fixed something broken                        |
| **chore**    | Maintenance, config, cleanup (no behavior change) |
| **refactor** | Code restructured, same behavior                  |
| **docs**     | README, comments, diagrams                        |
| **style**    | Formatting only (no logic change)                 |
| **test**     | Adding or fixing tests                            |
| **perf**     | Makes something faster or lighter                 |
| **ci**       | GitHub Actions, GitLab CI, pipelines              |
| **build**    | Dependencies, Dockerfiles, build tooling          |
| **revert**   | Undo a bad commit                                 |
