## Introduction to Python 🐍

Python is a high-level, interpreted programming language. It is known for its **readable syntax, simplicity, and versatility**, making it ideal for beginners and professionals alike.

### Why Python?
- Simple and readable syntax
- Cross-platform and open-source
- Large ecosystem of libraries and frameworks

### Common Uses
- **Web Development**: Django, Flask  
- **Data Science & Machine Learning**: NumPy, Pandas, TensorFlow  
- **Automation & DevOps**: Scripting, cloud SDKs  
- **Desktop Applications**: Tkinter, PyQt

### Print

The `print()` function outputs data. Example:

```python
print("hello world")
hello world
```
